# CW_4Poetry

Проект позволяет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

Для работы с платформой необходимо:

    Ввести поисковый запрос: "Разработчик"
    Ввести количество вакансий: "10"
    Ввести ключевые слова: "Python"
    Ввести интересующую зарплату: "50000"

Далее программа выведет отсортированный список вакансий
